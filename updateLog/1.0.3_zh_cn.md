# 1.0.3 更新日志

> 本次更新把 ATM 的「等级存取」正式改成「经验存取」，并补齐了排行榜、收购机和交易所的一批体验调整。

## ATM

### 等级存取 → 经验存取

- 界面仍然按**等级**输入，但机器里保存和显示的是**经验点**。
  - 27 级输入 1：把「27 级当前经验条 + 升到 28 级所需」整段经验存进 ATM，玩家变成刚好 26 级、经验条清空。
  - 取出时按「升 N 级所需的经验」返还。
- 新增「**全部存入**」「**全部取出**」。
- ATM 主界面显示「**已存经验**」，不再显示库存等级。
- 旧存档里的 `storedLevels` 会在读取时自动折算为经验点（新字段 `storedXp`），不需要手动改存档。

### 在线奖励

- 奖励从「+1 级」改为**经验值**：**基础 50 + 当前游戏日**。
  - 例如第 38 个游戏日可领 50 + 38 = **88 点经验**。
- 资格仍然只在每日结算那一刻在线才发放，每人每天限领一次。

### 主界面

- 「已存经验」文案简化。
- 「贷款欠款」与「信用额度」互换位置：
  - 第一行：余额 + 信用额度
  - 第二行：贷款欠款 + 可贷额度

### 排行榜

- 拆成两个页签：
  - **余额排行榜**：按账户余额排序，显示净值 / 余额 / 欠款，可「转账」。
  - **经验排行榜**：按 ATM 里已存的经验点排序，可「赠送」。
- **打开排行榜页面时实时重算一次**，不再等每日结算。
  - 只有打开排行榜（或排行榜开着时遇到结算/价格刷新）才会排序，普通存取款不触发。
  - 复杂度 `O(n log n)`，正常服务器规模可以忽略。
- **转账和经验赠送都要求对方在线**；离线玩家按钮置灰并标注「离线」，服务端会再校验。
- 经验赠送从自己的 ATM 已存经验中扣除，不收取手续费。

### 交易记录

- 从两个分类增加为三个：
  - **账户余额明细**
  - **贷款欠款明细**
  - **经验存取明细**（存入 / 取出 / 在线奖励 / 经验赠送，显示变动前经验 → 变动后经验）

## 自动售货机

- 「其他」大分类的所有商品**取消每日限购**，界面显示「不限量」。
- 附魔书格子仍然按配置每天限购。

## 自动收购机

- 每行新增「**出售全部**」按钮，由服务端按背包实际可卖数量结算。
- 价格调整：
  - 苹果 **4 / 个**
  - 西瓜（原来的西瓜片）**4 / 个**
  - 南瓜 **4 / 个**
  - 杂物新增**不祥之瓶 50 / 个**（放在不祥旗帜下面）
- 疯狂星期五：
  - 恢复**任意刷怪蛋**整类收购：`*_spawn_egg` 通配，原版和其他模组的刷怪蛋都算，基准价 **40**。
  - 抽中后界面上只显示一行「刷怪蛋（任意）」，卖任意一种刷怪蛋都按这一行结算。
  - 刷怪笼基准价改为 **40**。

## 基金交易所

- 列表新增「**累计**」列：当前价相对基金基准价的涨跌。
- 原「涨跌幅」改名「**日涨跌**」，仍然相对上次每日收盘价。
- 卖出页面显示**自己的份额**，并新增「**全部卖出**」。

## 配置与兼容

- 服务端 TOML：
  - 删除 `onlineRewardLevels`
  - 新增 `onlineRewardBaseExp = 50`、`onlineRewardPerDayExp = 1`
- `config/emerald_economy/acquire.json` 需要同步新价格与疯狂星期五池子（详见「更新说明」）。
- 世界存档自动迁移，不需要手改。
- **只需要改服务端配置**；其他玩家的客户端只需要安装新版模组 jar，不需要复制配置文件。
- 协议版本升级到 **6**，客户端和服务端必须同时更新，否则连接会被拒绝。
