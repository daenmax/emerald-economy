# 1.0.3 Changelog

> This release turns the ATM's "level storage" into "experience storage", adds the dual leaderboard and
> smooths out several acquisition / exchange workflows.

## ATM

### Level storage → experience storage

- You still enter **levels**, but the machine stores and displays **XP points**.
  - At level 27, entering 1 moves the XP from your current bar plus everything needed to reach level 28
    into the ATM; you end up at exactly level 26 with an empty bar.
  - Withdrawing returns the XP needed for the requested number of levels.
- Added **Store all** and **Withdraw all**.
- The main screen now shows **Stored XP** instead of stored levels.
- Old saves store `storedLevels`; it is converted to XP on load (new key `storedXp`), so no manual save
  editing is needed.

### Online reward

- The reward is now **XP** instead of "+1 level": **50 base + current game day**.
  - For example, day 38 grants 50 + 38 = **88 XP**.
- Eligibility is still granted only to players online at the daily settlement, once per day.

### Main screen

- The label is now simply **Stored XP**.
- **Debt** and **Credit limit** have swapped places:
  - First line: balance + credit limit
  - Second line: debt + available credit

### Leaderboard

- Two tabs:
  - **Balance ranking**: sorted by balance, showing net / balance / debt, with a **Send** action.
  - **Experience ranking**: sorted by stored ATM XP, with a **Gift** action.
- The page is **recomputed live whenever it is opened** instead of waiting for the daily settlement.
  - Only opening the leaderboard (or a settlement / price refresh while it is open) triggers sorting;
    normal deposits and withdrawals do not.
  - The cost is `O(n log n)`, negligible for normal server sizes.
- **Transfers and XP gifts require the recipient to be online**; offline players have a greyed-out button
  and an "(offline)" marker, and the server validates it again.
- XP gifts are taken from your stored ATM XP and cost no fee.

### Transaction history

- Now three tabs:
  - **Balance details**
  - **Debt details**
  - **XP details** (deposit / withdraw / online reward / XP gifts, showing XP before → after)

## Vending Machine

- All goods in the **Other** group are **no longer purchase-limited** and show "Unlimited".
- Enchanted book slots still follow the configured daily limit.

## Acquisition Machine

- Each row now has a **Sell all** button; the server computes the actual sellable amount from your inventory.
- Price changes:
  - Apple **4 each**
  - Melon (formerly melon slice) **4 each**
  - Pumpkin **4 each**
  - Ominous Bottle added at **50 each** (below the ominous banner)
- Crazy Friday:
  - **Any spawn egg** is back as a whole-class entry: the `*_spawn_egg` wildcard matches vanilla and
    modded eggs, base price **40**.
  - When picked, the screen shows one row "Spawn egg (any, modded included)"; any spawn egg in your
    inventory sells at that row's price.
  - Monster spawner base price is now **40**.

## Fund Exchange

- Added a **Total** column: current price vs the fund's base price.
- The old change column is now **Day** (vs the last daily close).
- The sell screen shows **your shares** and has a **Sell all** button.

## Configuration and compatibility

- Server TOML:
  - Remove `onlineRewardLevels`
  - Add `onlineRewardBaseExp = 50` and `onlineRewardPerDayExp = 1`
- `config/emerald_economy/acquire.json` must be updated with the new prices and Friday pool.
- World saves migrate automatically; no manual editing.
- **Only server-side configs are needed**; other players just install the new mod jar and do not copy any
  config files.
- The protocol version is now **6**; clients and the server must be updated together or the connection
  will be refused.
