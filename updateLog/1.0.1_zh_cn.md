# 绿宝石经济 v1.0.1 更新日志

> 发布日期：2026-10-17

## ATM 存取款机

### 新增：等级存取（搬的是等级，不是经验值）
- 每个玩家**默认关闭**，支付 **1000 余额**解锁一次后永久可用、无任何限制；
- 存 5 级 = 自己掉 5 级、ATM 库存 +5；取 5 级 = 自己升 5 级（35 → 36）；
- 存入不能超过当前等级、取出不能超过库存（等级不会被压负，经验条进度也不会被清零）；
- ATM 界面新增「等级存取」区块；交易记录里新增等级流水（金额列写「级」，不会因为「余额没变」被过滤掉）。

### 新增：每日在线奖励
- 每天**结算利息的那一刻**重置领取资格，**只有那一刻在线的玩家**才有当天的资格（不在线就没有，也不能事后补领）；
- 每天可领一次 **+1 级**；界面分「今日可领取 / 已领取 / 今日无资格」三种状态；
- 领取会写一条账户流水。

### 界面调整
- 面板加高，费率与利率信息移到标题下方，新增上述两个区块。

## 自动收购机

### 「整类」收购合并成一行
- 音乐唱片（任意，3/张）、树苗、花、蘑菇、马铠、鱼各占一行，卖背包里该类里的**任意一种**都行，**可以混着卖**；
- 每行的显示名可在内容文件里配置（`lang` / `name`）。

### 新增收购内容
- **林业产物**：所有树苗（1）、所有花（1）、所有蘑菇（1）、仙人掌（1）——树苗从「农业产物」移到林业产物；
- **农业产物**：毒马铃薯（10，排在马铃薯下面）；
- **杂物**：不祥旗帜（50，游戏里即「白色旗帜」这一件物品）、恶魂之泪（20）、岩浆膏（5，排在粘液球下面）、
  腐肉（1）、蜘蛛眼（1）、幽匿感测体（20）；粘液球调整为 2、烈焰棒调整为 5。

### 疯狂星期五
- 随机池：下界之星、鞘翅、三叉戟、海洋之心、回响碎片、刷怪笼、不祥之瓶 +
  **所有怪物的头颅**（骷髅 / 凋灵骷髅 / 僵尸 / 苦力怕 / 猪灵 / 龙首，共 6 种，基准价 **83**）+
  **所有怪物的刷怪蛋**（通配匹配，基准价 **52**）；
- 龙首已并入「所有怪物的头颅」这一项，不再单独列出、单独抽取；
- 删除不死图腾；
- **全服广播与界面横幅都带上每件的单价**；
- 收购数量不限（想卖多少卖多少，广播里也写着「不限数量」）。

## 自动售货机

- 「其他」新增子分类 **杂物**（在树苗之后），售卖**经验值**：10 点 / 100、100 点 / 800、1000 点 / 6000；
- 买下直接加到经验条上，**是经验点不是等级**（界面第二行有说明），图标用经验瓶示意；
- 三档商品与附魔书共用每日限购规则（每件每天 2 次）。

## 基金交易所

- **新增每日随机情绪修正**（`market.dailyRandomDrift`，默认 **±5%**，正负对称）：
  每日结算时给每支基金各随机一次。原来的「世界供给 + 天气」都是带方向的修正，长期会把行情拧成固定趋势
  （买一直涨的那几支、什么都不干就稳赚）；加上随机项后，**即使当天没有任何世界活动行情也会变，
  也没有哪支基金能长期单边走**。

## 配置变更

新增配置项（旧的 TOML 会自动补默认值）：

| 键 | 默认值 | 说明 |
| --- | --- | --- |
| `account.levelUnlockCost` | `1000` | 等级存取解锁费用（每人一次） |
| `account.onlineRewardLevels` | `1` | 在线奖励每天送几级 |
| `market.dailyRandomDrift` | `0.05` | 每日随机情绪修正幅度（±5%） |

- **配置文件注释改为中英双语**：`emerald_economy-server.toml` 的每一项、以及
  `config/emerald_economy/shop.json` / `acquire.json` 里的 `_comment` / `_format` 说明，
  现在都是「先中文、再英文」。旧文件里是旧注释，想看到双语注释请删掉对应文件让它重新生成
  （内容 JSON 也可以照抄新模板里的说明文字）。

## 兼容性与升级须知

1. **只支持 Minecraft 1.21.1 / NeoForge 21.1.x**（依赖范围已收紧为 `[1.21.1,1.21.2)` 与 `[21.1.0,21.2)`，
   Modrinth 不会再自动勾选 1.21.2 以上版本）。
2. **内容 JSON 不会自动更新**：新条目 / 新价格只在文件缺失时才从内置模板生成。
   想用本版的默认内容，请删除（先备份）`config/emerald_economy/shop.json` 与 `acquire.json`
   让服务端重新生成，或照格式手动补齐；只改价、不想要新条目时手动改那几行也可以。
3. **TOML 新键会自动补默认值**，但已存在的键不会覆盖旧值。
4. 旧存档兼容：新增字段缺失时按「未解锁 / 无库存 / 无今日资格」读取，不会读出乱数字。
5. 协议版本 2 → 3，**客户端与服务端都要更新**。
