# Emerald Economy v1.0.1 — Changelog

> Minecraft Java **1.21.1** · NeoForge **21.1.x**
> Released: 2026-10-17
> ⚠️ Network protocol **2 → 3**: client and server must both be on 1.0.1.

---

## ATM

### New: level storage (levels, not XP)
- **Locked by default** for every player; pay **1000** once to unlock it permanently, with no limits afterwards.
- Storing 5 levels drops you 5 levels and puts 5 levels into the ATM; withdrawing 5 levels adds 5 levels to you (35 &rarr; 36).
- You cannot store more than your current level, nor withdraw more than the ATM holds (levels never go negative and your XP bar progress is kept).
- The ATM screen has a new "Level storage" section; the transaction history gets level entries (the amount column is in **levels**, and they are no longer filtered out for "balance unchanged").

### New: daily online reward
- Eligibility is reset **at the moment interest is settled** each day; **only players online at that moment** get it (offline means no eligibility, and no claiming later).
- **+1 level**, once per day. The screen shows claimable / already claimed / unavailable today.
- Claiming writes an account transaction.

### Screen layout
- Taller panel; fees and interest rates moved under the title; the two new sections added.

## Acquisition Machine

### Whole-class buyout rows
- Music discs (any, 3 each), saplings, flowers, mushrooms, horse armors and fish each take **one row**; selling accepts any item of that class and **different kinds can be mixed in one sale**.
- Each row can be named in the content file (`lang` / `name`).

### New buyout content
- **Forestry produce**: all saplings (1), all flowers (1), all mushrooms (1), cactus (1) — saplings moved here from Farm produce.
- **Farm produce**: poisonous potato (10, right below potato).
- **Misc**: ominous banner (50 — in game this is the white banner item), ghast tear (20), magma cream (5, below slimeball), rotten flesh (1), spider eye (1), sculk sensor (20); slimeball changed to 2, blaze rod to 5.

### Crazy Friday
- Pool: nether star, elytra, trident, heart of the sea, echo shard, monster spawner, ominous bottle +
  **all mob heads** (skeleton / wither skeleton / zombie / creeper / piglin / dragon — six kinds, base price **83**) +
  **all spawn eggs** (wildcard match, base price **52**).
- The dragon head now lives inside "all mob heads" (no separate row, no separate roll).
- Totem of Undying removed.
- **The server-wide broadcast and the screen banner include the price of every item.**
- Sell quantity is unlimited (the broadcast says "unlimited quantity" as well).

## Vending Machine

- New **Misc** subcategory under "Other" (after Saplings) selling **XP points**: 10 for 100, 100 for 800, 1000 for 6000.
- Points go straight onto your XP bar — **experience points, not levels** (stated on screen); the icon is an experience bottle.
- These goods share the daily purchase limit with books (2 per good per day).

## Fund Exchange

- **New daily random mood correction** (`market.dailyRandomDrift`, default **±5%**, symmetric): rolled once per fund at each daily settlement. World supply and weather are directional corrections and used to push the market into a fixed trend (buy the risers, do nothing, profit); with the random term, **prices move even when nobody does anything, and no fund can trend one way forever**.

## Configuration

New options (existing TOML files get the defaults automatically):

| Key | Default | Meaning |
| --- | --- | --- |
| `account.levelUnlockCost` | `1000` | Level storage unlock cost (once per player) |
| `account.onlineRewardLevels` | `1` | Levels granted by the daily online reward |
| `market.dailyRandomDrift` | `0.05` | Daily random mood correction (±5%) |

- **Config comments are now bilingual**: every entry in `emerald_economy-server.toml`, plus the
  `_comment` / `_format` notes in `config/emerald_economy/shop.json` and `acquire.json`, now carry
  Chinese followed by English. Existing files still hold the old comments — delete them to regenerate
  (or copy the new notes from the templates).

## Compatibility and upgrade notes

1. **Minecraft 1.21.1 / NeoForge 21.1.x only** (dependency ranges tightened to `[1.21.1,1.21.2)` and `[21.1.0,21.2)`, so Modrinth no longer auto-selects 1.21.2+).
2. **Content JSON files are not updated automatically**: new entries / prices are only written when the file is missing. To pick up the new defaults, delete (back up first) `config/emerald_economy/shop.json` and `acquire.json` and let the server regenerate them, or add the entries by hand.
3. **New TOML keys are added with defaults**, but existing keys keep the values in your file.
4. Old saves stay compatible: missing fields read as "not unlocked / no stored levels / no reward today".
5. Protocol 2 → 3: **update client and server together**.
