# 绿宝石经济 v1.0.2 更新日志

> Minecraft Java 版 **1.21.1** · NeoForge **21.1.x**
> 发布日期：2026-10-18
> ⚠️ 网络协议版本 **3 → 4**，联机时**客户端与服务端必须同为 1.0.2**。

---

## ATM 存取款机

### 主界面重构
- 主界面现在只显示：**账户余额 / 信用额度 / 贷款欠款 / 可贷额度 / ATM 里存的等级**；
- 下方是一排功能按钮：**存款和取款、贷款和还款、交易记录、等级存取、在线奖励、排行榜**；
- 手续费、日息、计息起算线、贷款规则等说明全部移动到对应子页面。

### 新增：净值排行榜
- 每个游戏日**更新一次**（在每日结算时刷新），按 **净值 = 账户余额 - 贷款欠款** 从高到低排序；
- 显示名次、玩家、净值、余额、欠款；自己的那一行用金色高亮；
- 排行榜快照随世界存档持久化，服务器重启后仍是当天那份。

### 新增：玩家转账
- 排行榜每一行后面新增「转账」按钮，可以给任意玩家转任意金额；
- **手续费从转账金额里扣**：转 1000、费率 1% 时对方实际到账 990；
- 新增配置项 `account.transferFeeRate`，默认 `0.01`（1%），设为 0 即免费；
- 不能给自己转账、不能转给不存在 / 从未登录过的玩家；
- 收款人在线时会立刻收到到账提示，双方的交易记录里分别记为「转账支出 / 转账收入」。

## 自动收购机

### 农业产物
- 新增：小麦种子、甜菜种子、南瓜种子、西瓜种子（**8 个一份**，1 绿宝石 / 份）；
- 删除：竹子。

### 畜牧产物
- 新增：海龟蛋（20）、犰狳鳞甲（10）、河豚（20）；
- 河豚从「鱼类」里独立出来：鱼类标签改为本模组的 `emerald_economy:acquire/fishes`（不含河豚）。

### 矿物
- 新增：哭泣的黑曜石（5）、紫水晶块（2）、铁锭（4）、铜锭（4）、金锭（8）；
- 紫水晶碎片：2 → **15**。

### 林业产物
- 新增：紫颂花（5）、紫颂果（1）。

### 杂物
- 新增：藏宝图（20）、光灵箭（10）、箭（1）、鹦鹉螺壳（50）、蜘蛛网（5）；
- 藏宝图**只收带结构标记的已填写地图**（林地府邸 / 海底神殿 / 埋藏的宝藏等），
  普通已探索地图与空地图不收；内容文件里用 `"filter": "treasure_map"` 表示。

### 新分类：附魔回收
- 扫描玩家背包（含快捷栏）里所有带附魔的物品，附魔书也算；
- 每行显示：物品图标、名字、数量、每个附魔的回收价、整叠总价；
- 回收价 = **售货机里该附魔的最低价 ÷ 最大等级 × 当前等级**（向下取整、最低 1）；
  只看附魔，不看物品材质；
  例：经验修补 1560 + 保护 896/4×3 = 672 → 合计 **2232**；
- 点「回收」会先弹**二次确认**，确认后才整叠扣除并入账；
- 服务端会核对格子里的物品与数量，背包中途变化会拒绝并提示重开界面。

## 配置变更

| 键 | 默认值 | 说明 |
| --- | --- | --- |
| `account.transferFeeRate` | `0.01` | 玩家转账手续费率（1%），设为 0 表示不收费 |

**内容 JSON（`config/emerald_economy/acquire.json`）新增字段**：
- `"filter": "treasure_map"`：只收带结构标记的藏宝图；
- 新增标签 `emerald_economy:acquire/fishes`（鳕鱼 / 鲑鱼 / 热带鱼，不含河豚）。

## 兼容性与升级须知

1. 协议版本 **3 → 4**，客户端与服务端都要更新。
2. **内容 JSON 不会自动更新**：新增的收购条目、调价与新标签只在文件缺失时才从内置模板生成。
   想用本版默认内容，请删除（先备份）`config/emerald_economy/acquire.json` 让服务端重新生成，
   或照格式手动补齐。
3. **TOML 新键会自动补默认值**，但已存在的键不会覆盖旧值。
4. 旧存档兼容：排行榜与新增账户字段缺失时按「空榜单 / 无数据」读取，不会读出乱数字。
