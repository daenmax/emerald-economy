## ATM

### Main screen rebuilt
- The main screen now shows only **balance / credit limit / debt / available credit / stored levels**.
- Below it is a row of function buttons: **Deposit & withdraw, Loans & repayment, Transactions, Level storage, Online reward, Leaderboard & Transfer**.
- Fees, interest rates, the interest threshold and loan rules moved to the matching sub-screens.

### New: net worth leaderboard
- Updated **once per game day** (at the daily settlement), sorted by **net worth = balance - debt**.
- Shows rank, player, net worth, balance and debt; your own row is highlighted in gold.
- The snapshot is persisted in the world save, so a restart keeps the current day's ranking.

### New: player transfers
- Every leaderboard row has a **Send** button, allowing any amount to any player.
- **The fee is taken out of the amount**: sending 1000 with a 1% fee credits the recipient 990.
- New option `account.transferFeeRate`, default `0.01` (1%); set it to 0 for free transfers.
- You cannot transfer to yourself or to a player who has never joined the server.
- The recipient gets an instant notice when online; both sides get "Transfer out / Transfer in" entries in their history.

### Fixed: online reward button overlapped the text
- The **Claim reward** button used to sit on top of the hint text and separator; it now has its own row below
  the hints.
- The three states (available / already claimed / no eligibility today) are unchanged.

## Acquisition Machine

### Farm produce
- Added: wheat seeds, beetroot seeds, pumpkin seeds, melon seeds (**8 per batch**, 1 emerald per batch).
- Removed: bamboo.

### Livestock produce
- Added: turtle egg (20), armadillo scute (10), pufferfish (20).
- Pufferfish is split out of "fish": the fish row now uses this mod's `emerald_economy:acquire/fishes` tag (no pufferfish).

### Minerals
- Added: crying obsidian (5), amethyst block (2), iron ingot (4), copper ingot (4), gold ingot (8).
- Amethyst shard: 2 → **15**.

### Forestry produce
- Added: chorus flower (5), chorus fruit (1).

### Miscellaneous
- Added: treasure map (20), spectral arrow (10), arrow (1), nautilus shell (50), cobweb (5).
- Treasure maps **only accept filled maps with a structure marker** (woodland mansion / ocean monument / buried treasure); ordinary explored maps and empty maps are rejected. The content file uses `"filter": "treasure_map"`.

### New category: Enchantment recycle
- Scans every enchanted item in the player's inventory (hotbar included); enchanted books count too.
- Each row shows the icon, name, stack size, the recycle price of every enchantment and the whole-stack total.
- Recycle price = **vending min price / 3 / max level × current level** (rounded down, minimum 1); only enchantments matter, never the base material.
  Example: Mending 1560/3 = 520 + Protection 896/3/4×3 = 224 → **744**.
- Clicking **Recycle** opens a **second confirmation**; only then is the stack consumed and credited.
- The server re-checks the slot's item and count; if the inventory changed in the meantime the sale is refused.

### Crazy Friday: spawn eggs are now one "whole class" entry
- The pool is back to **9 entries**: nether star, elytra, trident, heart of the sea, echo shard, spawner,
  ominous bottle, all mob heads, and the spawn egg list.
- Three entries are rolled per Friday; when the spawn egg entry is picked, **one** of the 30 vanilla spawn eggs
  is chosen at random.
- Therefore **a Friday contains at most one spawn egg** — no more "two eggs among three items".
- The 30 eggs live in `friday.spawnEggs`; `friday.pool` references it with **`$spawn_eggs`**, so the whole list
  counts as **one** pool entry.
- To add another vanilla or modded spawn egg, add one line to `spawnEggs`. To give one egg a special price, add
  its exact ID to `friday.basePrices` (an exact item price beats the group price of **52**).
- The `*_spawn_egg` wildcard is still supported by the code, but the default config no longer uses it.

## Vending Machine

### "Misc" renamed to "Experience"
- The old subcategory that sold XP was renamed to **Experience** (ID stays `MISC`).
- The three XP goods are unchanged: 10 points for 100, 100 for 800, 1000 for 6000.

### New "Misc" subcategory
- A new **Misc** subcategory (ID `GENERAL`) follows Experience.
- It currently sells **glass at 1 balance each**.
- Like Experience, it ignores the enchantment unlock progression and is always available.

## Configuration

| Key | Default | Meaning |
| --- | --- | --- |
| `account.transferFeeRate` | `0.01` | Player transfer fee (1%); 0 disables it |

**New fields in `config/emerald_economy/acquire.json`**:
- `"filter": "treasure_map"` accepts only treasure maps with a structure marker.
- New tag `emerald_economy:acquire/fishes` (cod / salmon / tropical fish, no pufferfish).
- `friday.spawnEggs`: the spawn egg list (30 vanilla spawn eggs).
- `friday.pool` gains `"$spawn_eggs"`: references `spawnEggs`; the whole list counts as one pool entry.
- `friday.basePrices` gains `"$spawn_eggs": 52`.

**Changes in `config/emerald_economy/shop.json`**:
- The old "Misc" subcategory (ID `MISC`) is now displayed as **Experience** and uses the `shop.sub.exp` lang key.
- A new **Misc** subcategory (ID `GENERAL`) sells `{ "item": "minecraft:glass", "price": 1 }`.

**Language files**: new `emerald_economy.shop.sub.exp` (Experience / 经验); the ATM main-menu button
`screen.atm.menu.ranking` is now "Leaderboard & Transfer / 排行榜和转账".

## Compatibility and upgrade notes

1. Protocol **3 → 4**: update client and server together.
2. **Content JSON files are not updated automatically**: new entries, price changes, the new tag, the spawn egg list and the new vending subcategory are only written when the file is missing. To pick up the new defaults, delete (back up first) `config/emerald_economy/acquire.json` and `shop.json` and let the server regenerate them, or add the entries by hand.
3. **New TOML keys are added with defaults**, but existing keys keep the values in your file.
4. Old saves stay compatible: missing ranking / account fields read as "empty ranking / no data".
