# 1.0.5 Changelog

> This update extends the paid-unlock system to four features across three machines: the acquisition
> machine's **Enchantment recycle** and **Crazy Friday**, plus the vending machine's **enchanted-book
> category**, now require every player to pay a one-off **5000** unlock fee. The existing ATM
> **experience storage** unlock price was raised from 1000 to 5000. All four prices are configurable.

## Feature unlocks (once per player, permanent)

### General rules

- The following four features are **off by default for every player**. To use one, open its machine
  screen and press the unlock button:
  - **ATM · Experience storage** (existing feature, price change only)
  - **Acquisition machine · Enchantment recycle**
  - **Acquisition machine · Crazy Friday**
  - **Vending machine · Enchanted-book category**
- The fee is charged once; after unlocking the feature is **permanently available** with no further
  limits. Every unlock is recorded in the transaction history.
- Unlock state is persisted with the player's account and survives server restarts and relogs.

### Acquisition machine

- **Enchantment recycle**: while locked, the category only shows the unlock button and the fee note;
  the server does not even scan the inventory (no prices are offered). After unlocking it works as
  before.
- **Crazy Friday**: while locked, the category and the banner **still show** what is being bought today
  and at which price, but the Sell buttons do not appear and the server rejects the sale; on open days
  the banner notes that the feature is locked. An unpaid loan still blocks participation even when
  unlocked (existing rule unchanged).

### Vending machine

- **Enchanted-book category**: while locked, the bookshelf shows only the unlock button and fee note —
  no buy or upgrade buttons. The **Other** group (seeds / saplings / XP / misc) is **unaffected** and
  stays available.
- Do not confuse the two: the unlock fee is a **per-player gate**, while the slot-by-slot upgrade
  progression of the bookshelf remains **shared server-wide** as before.

### In-screen notices

- Unlock success, insufficient balance and duplicate unlocks are reported both in chat and inside the
  machine screen.
- Attempting a locked operation from an outdated client is rejected server-side with a hint to unlock
  first.

## Price change

- The ATM experience-storage unlock cost default changed **1000 → 5000** (`account.levelUnlockCost`).
- **Crazy Friday pool base prices were raised across the board** (actual buyout price = base × 5-10
  for the day):

| Pool entry | Old base | New base |
| --- | --- | --- |
| Nether star | 133 | **200** |
| Elytra | 100 | **200** |
| Trident | 75 | **100** |
| Heart of the sea | 58 | **80** |
| Echo shard | 33 | **60** |
| Monster spawner | 40 | 40 |
| Ominous bottle | 42 | **40** |
| Mob heads (6 kinds) | 83 | **90** |
| Spawn egg (any, incl. mods) | 40 | **70** |

## Configuration changes

- Three new server config entries (all default **5000**):
  - `shop.enchantBookUnlockCost` — enchanted-book category unlock cost on the vending machine
  - `acquire.enchantRecycleUnlockCost` — enchant recycle unlock cost on the acquisition machine
  - `acquire.crazyFridayUnlockCost` — Crazy Friday unlock cost on the acquisition machine
- `account.levelUnlockCost` default is now 5000 (key unchanged).
- Set any of them to `0` to make the unlock free (the button still has to be pressed once).
- **Existing config files are not overwritten automatically**: add these keys by hand or delete
  `serverconfig/emerald_economy-server.toml` to regenerate. Missing keys simply fall back to the
  5000 default, so nothing breaks either way.
- **Crazy Friday base prices live in `config/emerald_economy/acquire.json` under
  `friday.basePrices`**: this update only changes the built-in default template — servers that
  already generated that file keep the old prices. Update the nine values by hand (table above) or
  back up and delete `acquire.json` to regenerate it. Back up your own custom entries (e.g. modded
  crops) before regenerating.

## Compatibility and saves

- **Old saves upgrade seamlessly**: after this update every player's unlock records are checked —
  **a feature without an unlock record counts as locked** and must be paid for again:
  - Players who had already unlocked experience storage keep it (the legacy flag is still read,
    nothing is lost);
  - Enchantment recycle, Crazy Friday and the enchanted-book category start **locked for all existing
    players** and need a one-off payment on the corresponding machine.
- Unlock data is persisted inside `emerald_economy.dat` (new `unlocks` list, backward compatible with
  the old boolean field).
- Protocol version bumped to **8** (vending / acquisition snapshots gained unlock state and cost
  fields). **Client and server must be updated together**, otherwise the connection is refused.
