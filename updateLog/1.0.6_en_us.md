# 1.0.6 Changelog

> This update adds buyout prices for a few common items on the acquisition machine and introduces
> a batch buyout for bowls (4 per batch). No new config keys and no protocol change — old saves and
> existing clients keep working.

## Acquisition machine

### New buyout entries

| Category | Item | Price | Batch |
| --- | --- | --- | --- |
| Farm produce | Lily Pad | 1 each | 1 |
| Livestock produce | Ink Sac | 1 each | 1 |
| Misc | Tripwire Hook | 1 each | 1 |
| Misc | Bowl | 1 per batch | 4 |

- **Bowls** are bought in batches: **4 bowls = 1 balance**, shown as "per 4 &rarr; 1" on screen.
  When the amount box holds fewer than 4, pressing Sell automatically switches to selling every full
  batch you have (existing behaviour unchanged).
- The other three are bought per item, following the same rules as the rest of their category
  (whole-tag rows, Sell all, owned-count hints, etc. are unchanged).

## Configuration changes

- Only the built-in default `acquire.json` template changed. **Servers that already generated
  `config/emerald_economy/acquire.json` will not receive the new entries automatically**: add the
  four rows by hand, or back up and delete the file so it is regenerated.
- `crabbersdelight:can` is an item from an external mod, so it was only added to this machine's live
  config, not to the default template — packs without Crabber's Delight will not see that row.

## Compatibility and saves

- No config keys, protocol version or save format changed.
- Run `/ee reload` in game after editing `acquire.json`; no restart needed.

## Verification

- `gradlew build` passes.
- `SelfTest` gained assertions: lily pad 1, ink sac 1, tripwire hook 1, bowl priced 1 per unit with
  a batch of 4.
