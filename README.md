# 绿宝石经济 · Emerald Economy

[Modrinth 下载](https://modrinth.com/mod/emerald-economy-daenmax) · [GitHub 源码](https://github.com/daenmax/emerald-economy)

> Minecraft Java 版 **1.21.1** + **NeoForge** 的经济玩法模组：把绿宝石变成真正的货币，
> 围绕一个**统一的玩家账户**搭出六套互相打通的经济系统。
>
> 模组 ID：`emerald_economy` · 包名：`cn.daenx.mc.emeraldeconomy`

---

## 这是什么

服务器里的绿宝石通常只是「一种可以交易的材料」。这个模组把它变成**货币本身**：
所有玩法最终都从同一个账户里扣钱、进钱，形成一个闭环。

1. 把背包里的绿宝石通过 **ATM** 存进账户（收 1% 手续费），还能在 ATM 里**存取经验**、
   每天领一次**在线奖励**；ATM 的**余额 / 经验排行榜**打开时实时刷新，榜单上可以给其他玩家**转账 / 赠送经验**。
2. 用余额去 **基金交易所** 买卖七支基金赚差价（行情会被挖矿、伐木、收割、打怪、
   村民交易与当天的天气推动，**每天还有 ±5% 的随机情绪修正**，所以没有「稳涨」的基金）。
3. 用余额去 **抽奖机** 下注，次日结算时开奖。
4. 用余额在 **自动售货机** 买满级附魔书、种子、树苗与**经验值**。
5. 把挖到 / 种出 / 打到的物品卖给 **自动收购机**，逢 5 的日子还有「疯狂星期五」高价收购；
   带附魔的装备与附魔书还可以走**附魔回收**换钱。
6. 缺钱可以 **贷款**，每天结算时计息；**欠款没还清之前不能抽奖，也不能参加疯狂星期五**。

所有机器都必须放在**红石块正上方**才能使用，否则右键会提示「未接通红石电源」。

## 快速开始

```bash
# 编译（产物在 build/libs/，build.bat 会再复制一份到 build/）
./gradlew build          # 或者直接双击 build.bat

# 启动开发用服务端（会自动跑一遍引擎自检，结果打印在控制台）
./gradlew runServer

# 启动客户端
./gradlew runClient
```

装到正式客户端 / 服务器：把 `build/libs/emerald_economy-<版本>.jar` 丢进 `mods/` 即可
（需要 NeoForge 21.1.x for Minecraft 1.21.1）。

**第一次进游戏怎么玩**：

1. 合成：五台机器共用**同一套配方**，只有正中间那一格不同 —— 完整配方见下面的**合成配方**一节。
   首次拿到红石就会解锁全部五个配方（配方书里能直接搜到）。
2. 在红石块上放机器（**必须**），右键打开界面。
3. 想快速试玩：`/ee give @s 10000` 直接给账户打钱。

## 合成配方

五台机器共用**同一套配方**，只有正中间那一格不同：外围八格是红石元件，围着各自的核心物品。

|  |  |  |
| :---: | :---: | :---: |
| 红石 | 粘性活塞 | 漏斗 |
| 侦测器 | **核心物品** | 拉杆 |
| 红石中继器 | 箱子 | 红石比较器 |

五台机器各自的核心物品（放在正中间那一格）：

| 机器 | 核心物品 |
| --- | --- |
| ATM | 绿宝石 |
| 交易所电脑 | 红石灯 |
| 抽奖机 | 时钟 |
| 自动售货机 | 物品展示框 |
| 自动收购机 | 炼药锅 |

每个配方出一台机器。首次拿到红石就会解锁全部五个配方，配方书里直接搜「绿宝石」也能找到。

## 玩法细则

### 统一账户
- 每个玩家一个账户：**余额 / 欠款（区分本金与利息）/ 信用额度 / 流水 / 基金持仓**，全部存进世界存档。
- 存取款各有 1% 手续费；**日息 0.500%，但余额 ≥ 200 才开始计息**（低于 200 不计息）。
- 贷款日息 2%（复利），信用额度默认 1000。

### ATM
- 主界面只显示**账户余额 / 信用额度 / 贷款欠款 / 可贷额度 / ATM 里已存的经验**，
  下面一排按钮进入六个功能页：**存款和取款、贷款和还款、交易记录、经验存取、在线奖励、排行榜和转账**。
  手续费、日息、计息起算线等说明都放在对应功能页里，不再堆在主界面。
- 「**存入全部**」把背包里的绿宝石一次性存完；「**取出全部**」把余额全部取成绿宝石，
  **背包放不下就整笔失败**（不会把绿宝石丢在地上）。
- 「交易记录」按钮进入流水界面，分成**账户余额明细 / 贷款欠款明细 / 经验存取明细**三个分类，
  每条都显示**变动前 → 变动后**；经验分类里的金额单位是「经验」。
- **经验存取**（默认关闭）：界面按**等级**输入，ATM 里存的是**经验点**。
  例如当前 27 级，输入 1，就会把「27 级当前经验条 + 升到 28 级所需」这一整段经验存进去，
  玩家变成刚好 26 级、经验条清空；「全部存入 / 全部取出」一次搬完。
  每个玩家要先用 **5000 余额**解锁（一次性，永久可用），解锁后没有任何限制：
  存入不能超过当前等级，取出不能超过 ATM 里存的经验。
- **在线奖励**：每天**结算利息的那一刻**重置领取资格，**只有那一刻在线的玩家**才有当天的资格
  （不在线就没有，也不能事后补领）；当天可以领一次 **基础 50 + 当前游戏日** 点经验
  （例如第 38 天可领 88 点），过了这一天的资格自动作废。
  界面会写清「今日可领取 / 已领取 / 今日无资格」。
- **排行榜**：分成两个分类 —— **余额排行榜**（按账户余额排序，显示净值 / 余额 / 欠款）与
  **经验排行榜**（按 ATM 里已存的经验点排序，只显示经验列）。每次**打开排行榜页面都会实时重算一次**，
  不再等每日结算；自己那一行会高亮。
- **玩家转账**：余额榜每行后面有「转账」按钮，可以给任意玩家转任意金额。
  手续费从转账金额里扣：**转 1000、费率 1% 时对方实际到账 990**，手续费率可在配置里调整。
- **经验赠送**：经验榜每行后面有「赠送」按钮，把 ATM 里已存的经验点送给对方，**不收手续费**。
- **转账 / 赠送都要求对方在线**：离线玩家的按钮会置灰，名字后面标注「离线」；服务端也会再校验一次。

### 基金交易所
- 七支基金：矿业 / 农业 / 畜牧 / 建筑 / 水电 / 狩猎 + 综合（由前六支加权指数生成）。
- 价格引擎：动量衰减 → 偏离度 → 均值回归 → 随机噪声 → 动量约束 → 硬性边界，默认每 5 分钟更新一次。
- 世界供给会推动行情：挖矿、伐木、收割成熟作物、杀被动动物、杀怪物、倒水 / 倒熔岩、与村民交易。
- **每日结算时每支基金还会各自获得一个 ±5% 的随机情绪修正**（`dailyRandomDrift`）：
  即使今天谁都没做任何事，行情也会变，而且没有任何一支基金能长期单边走 —— 所以
  「买入一直涨的那几支然后什么都不干」是行不通的。
- 列表里有**两列涨跌**：**日涨跌** = 当前价较上次每日结算的收盘价；**累计** = 当前价较基金基准价。
  日涨跌每天结算后会重新起算，累计涨跌看的是这支基金从开盘以来的总表现。
- 点「卖出」进入交易页时，页面会显示**自己当前持有的份额**，并提供「**全部卖出**」按钮。
- 买入页的份额输入框下方会提示**「按当前余额最多可买多少份」**（已把手续费算进去），
  旁边同时显示**今日还能买多少份**，不用自己算。
- **每人每天有买卖份额上限**：默认最多买入 10 份、卖出 20 份，统计的是**份额**而不是交易次数，
  七支基金**合计**共享同一个额度（今天买了矿业 5 份 + 农业 3 份，就只剩 2 份额度）。
  额度在游戏日切换时自动重置；「全部卖出」也会自动只卖到今日剩余额度为止。
- **每日涨跌幅上限（涨停 / 跌停）默认 ±10%**：当天价格被限制在「上一日收盘价 ±10%」以内，
  每 5 分钟的价格波动和每日结算后的开盘价都不会突破这个范围。
- 买卖收 2% 手续费（最低 1），同一支基金 5 秒交易冷却。

### 抽奖机
- 三个场次：猜单双（1.95 倍）、猜大小（1.95 倍）、猜尾数（9.5 倍），每天每场次一次。
- 每日结算时开奖并全服广播；界面上的「上次开奖」会写清**这一期余额是加了还是没变、加了多少**。
- **还有贷款没还清时不能下注**（界面仍可打开看赔率与开奖结果）。

### 自动售货机
- **两大分类**：附魔书 / 其他。附魔书下面按 武器 / 远程 / 工具 / 盔甲 / 通用与诅咒 五个子分类排版，
  每一条显示**等级**与**适用物品**，价格来自配置里的分类区间（例如锋利 896-1280，风爆 1560-2560）。
- **附魔书大分类要先付费解锁**：每个玩家默认买不了附魔书（界面只显示解锁按钮），
  花 **5000 余额**（可配置）一次性解锁后永久可用；
  「其他」大分类不受影响，随时可买。解锁费用是**每个玩家自己的门槛**，
  附魔书格子的「逐格升级」进度仍然是全服共享的。
- 附魔书格子要**全服一起花钱解锁**（每级 512-1280 随机，同一级价格固定），
  升级时会广播「解锁了哪个附魔」。
- 「其他」有四个子分类：**种子**（小麦种子 8/个）、**树苗**（橡树 / 白桦 16/个）、
  **经验**（卖**经验值**：10 点 100、100 点 800、1000 点 6000）、
  **杂物**（目前卖玻璃，1 余额 / 个）。都不参与解锁进度，随时可买，而且**不限购**。
- 买经验值给的是**经验点**，不是等级：1000 点经验值大约是「从 0 级练到 26 级」的量
  （作为参考，从 0 级升到 30 级一共需要 1395 点经验值），买下后直接加到经验条上。
- **只有附魔书格子**每人每天限购 2 次；「其他」大分类的商品不限量。

### 自动收购机
- 五个常驻分类：**农业产物 / 畜牧产物（含鱼肉类与骨头）/ 矿物（含下界合金碎片）/
  林业产物（原木 + 树苗 / 花 / 蘑菇 / 仙人掌）/ 杂物**（含不祥旗帜、不祥之瓶），外加第六个特殊分类
  **附魔回收**。分类、物品、价格都能在 `acquire.json` 里自由增减，
  完整的默认价表见 **默认数值与价格总表**一节。
- **「整类」收购占一行**：唱片（任意一种都行，3/张）、树苗、花、蘑菇、鱼各自只占一行，
  不会把几十种唱片一件件列出来。卖的时候背包里是这一类里的哪一种都可以，甚至可以混着卖。
  马铠**不合并**，按品质分成 4 条单独收：皮革 10、铁 50、金 100、钻石 200。
- 每行有「**出售**」和「**出售全部**」两个按钮：前者按数量框里的数量卖，
  后者由服务端直接按背包里实际可卖的数量一次卖完（藏宝图、整类行也能准确统计）。
- **背包里没有的物品，出售按钮是灰的**（每行还会显示「拥有 N」），
  数量不够「一份」的也一样点不动，不用点了才发现卖不掉。
- **批次收购**：鸡蛋、羽毛、小麦 / 甜菜 / 南瓜 / 西瓜种子都要凑够 **8 个**才算一份，
  碗要凑够 **4 个**算一份（8 个 = 1 绿宝石，4 个碗 = 1 绿宝石）。界面上会写「每 8 个 → 1」。数量框里填的不足一份时，
  界面会**自动改成把手里的整份全卖掉**（框里的数字会跟着变），
  所以「我有 16 个鸡蛋」点一下出售就是卖 16 个、换 2 绿宝石。
- **附魔回收**（每个玩家花 **5000 余额**一次性解锁后才能用）：把背包（含快捷栏）里
  所有带附魔的物品列出来（附魔书也算），
  每行显示物品图标、名字、数量、每个附魔的回收价和整叠总价。
  回收价只看附魔，不看物品材质：**售货机里该附魔的最低价 ÷ 3 ÷ 最大等级 × 当前等级**。
  例：经验修补最低价 1560、最大等级 1、等级 1 → 520；保护最低价 896、最大等级 4、等级 3 → 224，
  合计 744。点「回收」会先弹**二次确认**，确认后才整叠扣除并入账，防止误操作。
- **藏宝图**只收带结构标记的已填写地图（林地府邸 / 海底神殿 / 埋藏的宝藏等），
  普通已探索地图与空地图不收。
- **疯狂星期五**（每个玩家花 **5000 余额**一次性解锁后才能参加）：逢 5 的游戏日随机抽 3 件稀有物品
  按 **5-10 倍**收购，广播里会**带上每件的单价**。
  随机池一共 **9 个条目**：下界之星、鞘翅、三叉戟、海洋之心、回响碎片、刷怪笼、不祥之瓶、
  **所有怪物的头颅**、**任意刷怪蛋**。每次从这 9 个里随机抽 3 个；抽中整类条目时，
  界面上只显示一行（头颅一行 / 刷怪蛋一行），所以**一期最多只会出现 1 行头颅和 1 行刷怪蛋**。
  - **所有怪物的头颅**：骷髅头颅、凋灵骷髅头颅、僵尸头颅、苦力怕头颅、猪灵头颅、**龙首**，
    共 6 种（龙首就在这一项里，不再单独列出、也不再单独抽取），基准价 **90**。
  - **任意刷怪蛋**：`*_spawn_egg` 通配，原版和**其他模组**的刷怪蛋都算，基准价 **70**。
    抽中后玩家卖背包里任意一种刷怪蛋都按这一行的价格结算，不需要和当天显示的某种蛋一致。
  未解锁时列表与横幅照常显示（看得到今天收什么、多少钱），但点不到出售；
  **欠款没还清时同样不能参加**。
- 收购所得直接进账户，不收手续费。

### 机器外观与挖掘
五台机器都是 **1×1×2 的两格方块**（正面朝向放置者），模型与贴图在 Blockbench 里制作，

## 配置

服务端配置：`<存档目录>/serverconfig/emerald_economy-server.toml`
（专用服务器在 `config/` 下；开发环境是 `run/config/`）。

> **只需要改服务端。** TOML 与 `config/emerald_economy/*.json` 都由服务端读取并通过快照下发给客户端；
> 其他玩家的客户端**不需要复制任何配置文件**，只要安装同一版本（协议版本一致）的模组 jar 即可。

游戏内：**ESC → 模组 → Emerald Economy → 配置**。
这个按钮**只有服主 / OP（权限等级 ≥ 2）能改**，其他玩家点开只会看到提示。

主要能调的东西：

| 节 | 内容 |
| --- | --- |
| `account` | 存取款手续费率、日息与**计息起算余额**、贷款日息、信用额度、保留流水条数、**经验存取解锁费用**、**在线奖励基础经验与每日递增**、**玩家转账手续费率** |
| `market` | 价格更新间隔、动量与回归参数、**每日随机情绪修正幅度**、**每日涨跌幅上限**、手续费、交易冷却、**每人每日买卖份额上限**、各基金基准价 / 波动率 / 供给量、天气表、新闻事件表 |
| `lottery` | 三个场次的赔率、每日下注次数 |
| `shop` | 初始格子数、升级费用区间、**附魔价格与分类总表**、其他商品表、每日限购、不售卖的附魔、**附魔书大分类解锁费用** |
| `acquire` | 疯狂星期五间隔 / 物品池 / 基准价与倍率、**附魔回收解锁费用**、**疯狂星期五解锁费用**；各分类的价格表在 `acquire.json` 里 |

### 卖什么 / 收什么：两份可以直接编辑的 JSON

自动售货机的货架和自动收购机的价格表放在 `config/emerald_economy/` 下（第一次启动自动生成）：

| 文件 | 能改什么 |
| --- | --- |
| `shop.json` | 「大分类 → 子分类 → 商品」。附魔书用 `enchants`（`id` + `min`/`max` 价格区间）；普通商品用 `items`（`item` + `price`）；**经验值商品**也用 `items`，写成 `exp` + `price`（买下直接加经验点）。名字可以写翻译键 `lang`，也可以直接写 `name` |
| `acquire.json` | 「分类 → 条目」。每条形如 `{"item":"minecraft:wheat","price":1}`，或 `{"tag":"minecraft:saplings","price":1}` 收一整类（支持原版 / 本模组物品标签，**标签条目在界面上只占一行**）；`"batch": 8` 表示 8 个算一份；`"lang"` 是这一行的显示名；`"filter": "treasure_map"` 表示只收带结构标记的藏宝图；末尾 `friday` 段是疯狂星期五的池子（支持具体物品、`#标签` 与 `*通配`；`*_spawn_egg` 表示任意刷怪蛋整类）、`poolMaxPicks`（每个池子条目每天最多挑几件）与 `basePrices`（基准价）。**附魔回收分类由服务端扫描背包生成，不写在 JSON 里** |

**改完在游戏里执行 `/ee reload` 立刻生效**（不用重启；写错了会保留上一次的内容并在日志里报错）。

> **从旧版本升级（等级存取 → 经验存取）**：服务端配置里的 `onlineRewardLevels` 已删除，
> 改为 `onlineRewardBaseExp`（默认 50）与 `onlineRewardPerDayExp`（默认 1）；旧键留着不会报错，
> 但不再生效。世界存档里的 `storedLevels` 会在读取时自动折算成经验点（新键 `storedXp`），
> 不需要手动改存档。`acquire.json` 的西瓜 / 南瓜 / 苹果 / 不祥之瓶 / 周五任意刷怪蛋与
> 刷怪笼基准价改动需要手动同步，或直接使用新版本的默认 `acquire.json`。

> 升级到新版本后，如果你之前已经生成过这两份 JSON，**新加的商品 / 条目不会自动出现**
> （服务端只在文件缺失时才写默认模板）。想用新的默认内容，就把
> `config/emerald_economy/shop.json`、`acquire.json` 删掉（先备份）让服务端重新生成，
> 或者照上面的格式手动补几条。

`shop.json` 片段：加一个大分类 / 子分类 / 两件商品（一件物品、一份经验值）。

```json
{
  "groups": [
    {
      "id": "OTHER",
      "lang": "shop.group.other",
      "name": "其他",
      "icon": "📦",
      "unlockable": false,
      "subcategories": [
        { "id": "SEED", "name": "种子", "items": [ { "item": "minecraft:wheat_seeds", "price": 8 } ] },
        { "id": "MISC", "name": "杂物", "items": [ { "exp": 1000, "price": 6000 } ] }
      ]
    }
  ]
}
```

`acquire.json` 片段：加一个分类，收所有树苗（每份 1 绿宝石，界面上占一行）。

```json
{
  "categories": [
    {
      "id": "FORESTRY",
      "name": "林业产物",
      "items": [
        { "item": "minecraft:oak_log", "price": 1 },
        { "tag": "minecraft:saplings", "price": 1, "lang": "acquire.tag.saplings" },
        { "item": "minecraft:filled_map", "price": 20,
          "filter": "treasure_map", "lang": "acquire.item.treasure_map" }
      ]
    }
  ]
}
```

两份文件的默认模板在模组 jar 里（`data/emerald_economy/economy/`），
生成脚本是 `tools/gen_economy_json.py`。

其余用 `key=value` 字符串列表表示的表格（天气修正、随机事件、基金参数）仍写在 TOML 里：

```toml
weatherModifiers = ["RAIN:EMR_AGR=0.08", "THUNDER:EMR_HYD=0.090"]
marketEvents = ["EMR_MIN|0.08|news.vein_found", "ALL|-0.06|news.recession"]
```

> **改了默认值之后记得删旧配置**：NeoForge 只在「缺少某个键」时写入默认值，
> 已经存在的键会一直沿用文件里的旧值。删掉 `emerald_economy-server.toml`（先备份）再启动即可。

## 常见问题与配置教程（小白向）

这一节只讲**不能（或不好）在游戏内模组配置界面里改**的内容：
`shop.json`、`acquire.json`、物品标签（datapack）和 TOML 里的列表型参数。
手续费、利率、赔率、限购次数、基金基准价这类单个数值，请直接在
**ESC → 模组 → Emerald Economy → 配置**里改，不要手改文件。

### 0. 改文件前的 5 条通用规则

1. **文件在哪**
   - 单人游戏：`.minecraft/config/emerald_economy/shop.json` 与 `acquire.json`
     （Windows 下 `.minecraft` 一般在 `%APPDATA%\.minecraft`，整合包则在各自实例目录里）
   - 专用服务器：服务器根目录的 `config/emerald_economy/`
   - 这两个文件是**整个游戏 / 服务器共用**的，不在某个存档目录里。
   - 联机时只需要改**服务端**的文件；客户端不用改。但客户端也要安装对应模组，
     否则物品图标 / 名字可能显示不出来。
2. **先备份**：把 `shop.json` 复制成 `shop.json.bak`，改坏了随时还原。
3. **必须是合法 JSON**
   - 用 VS Code / Notepad++ 打开，编码选 **UTF-8（无 BOM）**；
   - 不要写 `//` 或 `#` 这类注释；文件里的 `"_comment"` 是普通字段，可以保留；
     （字符串里的 `#` 是标签写法，例如 `"#minecraft:saplings"`，这是正常的，不是注释）
   - 最后一项后面不要多写逗号；
   - 不确定就复制到在线 JSON 校验器里检查。
4. **改完执行 `/ee reload`**（需要 OP）。成功会提示「内容已加载：售货机 …；收购机 …」。
   如果提示「有文件解析失败」，说明 JSON 写错了，旧内容会被保留；
   去 `logs/latest.log` 搜 `[内容] 解析` 看具体原因。
5. **物品 ID 怎么找**
   - 在聊天框输入 `/give @s ` 后按 Tab，游戏会列出所有物品 ID；
   - 或开启 `F3 + H` 高级提示，把鼠标悬停在物品上看 ID；
   - 格式永远是 `命名空间:物品名`，例如 `minecraft:wheat`、`farmersdelight:tomato`；
   - 冒号前面就是模组 ID（`farmersdelight:` 表示农夫乐事）；
   - 配置里只能写**物品 ID**，不能写 NBT、附魔、自定义名字或数量。

> 下面示例里的 `...` 表示「省略，保持原样」，实际文件里不能写 `...` 或注释。

### 1. 自动收购机：添加农作物 / 其他模组物品

#### 1.1 加到已有分类（最简单）

比如把农夫乐事的番茄加进「农业产物」：

1. 在 `acquire.json` 里找到 `"id": "AGRICULTURE"`；
2. 在它的 `items` 数组里加一条：

```json
{
  "item": "farmersdelight:tomato",
  "price": 2
}
```

3. `/ee reload`，打开收购机就能看到「番茄 2/个」。

#### 1.2 几个物品算一份（batch）

```json
{
  "item": "farmersdelight:tomato",
  "price": 2,
  "batch": 4
}
```

意思是：**4 个番茄算 1 份，每份 2 绿宝石**。
卖 10 个番茄 → 按 2 份算，扣 8 个，给 4 绿宝石，剩 2 个留在背包。

#### 1.3 新建一个分类

```json
{
  "id": "MOD_CROPS",
  "name": "模组农作物",
  "items": [
    { "item": "farmersdelight:tomato", "price": 2 },
    { "item": "farmersdelight:cabbage", "price": 2 },
    { "item": "farmersdelight:onion", "price": 2 }
  ]
}
```

把这个对象放进 `acquire.json` 顶层的 `"categories"` 数组里（注意前后逗号）。
- `id` 随便起，但不要用保留的 `FRIDAY`（疯狂星期五）和 `ENCHANT`（附魔回收）；
- 分类在界面上的顺序 = 文件里的顺序；
- 没有 `lang` 时用 `name` 显示；**自己加的分类建议只写 `name`，不要写 `lang`**，
  否则可能显示成未翻译的键名；
- 如果分类里的物品全都不存在，这个分类会显示为空或被跳过。

#### 1.4 整类收购（tag，进阶）

```json
{
  "tag": "minecraft:saplings",
  "price": 1,
  "name": "树苗（任意）"
}
```

- 标签必须是游戏里真实存在的物品标签；
- 原版标签如 `minecraft:saplings`；NeoForge 通用标签常用 `c:` 前缀；
- 标签条目在界面上只占一行，卖这一类里的任意一种都行，也可以混着卖；
- **普通分类的 `tag` 字段不要写 `#`**（写成 `minecraft:saplings`）；
  `#` 只用在疯狂星期五的 `pool` 里；
- 不确定标签是否存在，就逐个写 `item` 最稳。

#### 1.5 删除 / 下架某个物品

直接把那一条 `{ ... }` 删掉，`/ee reload`。
**不要用 `"price": 0` 来下架**——价格最小会被修正成 1，仍然会收。

### 2. 自动售货机：添加商品 / 子分类 / 大分类

#### 2.1 往已有子分类加普通商品

在 `shop.json` 里找到对应子分类的 `items`，例如「杂物」：

```json
{
  "id": "GENERAL",
  "name": "杂物",
  "items": [
    { "item": "minecraft:glass", "price": 1 },
    { "item": "farmersdelight:tomato", "price": 3 }
  ]
}
```

- 一次购买给 **1 个**物品；
- 价格单位是账户余额（绿宝石），不是背包里的绿宝石物品；
- 每个格子每人每天最多买 2 次（这个次数在 TOML / 配置 GUI 里改）。

#### 2.2 新建一个子分类

```json
{
  "id": "FOOD",
  "name": "食物",
  "icon": "🍎",
  "items": [
    { "item": "farmersdelight:tomato", "price": 3 },
    { "item": "farmersdelight:cabbage", "price": 3 }
  ]
}
```

把它放进 `OTHER` 大分类的 `subcategories` 数组里；顺序就是界面上的标签顺序。
`id` 不要和已有子分类重复（已有 `SEED` / `SAPLING` / `MISC` / `GENERAL`）。

#### 2.3 新建一个大分类

```json
{
  "id": "MOD_FOOD",
  "name": "模组食物",
  "icon": "🍲",
  "unlockable": false,
  "subcategories": [
    {
      "id": "COOKED",
      "name": "熟食",
      "items": [
        { "item": "farmersdelight:hamburger", "price": 5 }
      ]
    }
  ]
}
```

- 普通商品的大分类一定要写 `"unlockable": false`；
- `"unlockable": true` 只给附魔书用，自己加普通商品不要用。

#### 2.4 经验值商品

```json
{ "exp": 100, "price": 800 }
```

买下直接加 **100 点经验**（不是 100 级），价格 800 余额。

#### 2.5 附魔书（进阶，谨慎）

附魔书条目长这样：

```json
{ "id": "minecraft:mending", "min": 1560, "max": 2560 }
```

- 加一个新的附魔会**改变全服解锁格子的总数**（后面格子的升级费用也会跟着变）；
- 附魔必须已经在游戏里注册（原版或已安装的模组）；
- 售货机里该附魔的最低价也会影响**附魔回收**的回收价（回收价 = 最低价 ÷ 3 ÷ 最大等级 × 当前等级）；
- 不懂就别动附魔表。

#### 2.6 自定义显示名：用 `name`，别乱写 `lang`

`lang` 是翻译键，会被加上 `emerald_economy.` 前缀去语言文件里查。
自己加的分类 / 子分类 / 收购行，**直接写 `"name": "中文名"` 最稳**；
写了不存在的 `lang` 会显示成 `emerald_economy.xxx` 这种键名。

### 3. 疯狂星期五：添加单件奖励 / 调价 / 限制数量（进阶）

`friday.pool` 里可以写：

- 具体物品：`"minecraft:dragon_egg"`
- 标签：`"#minecraft:saplings"`
- 通配：`"*_spawn_egg"`（默认配置用它表示「任意刷怪蛋」，会匹配所有以 `_spawn_egg` 结尾的物品，
  包括其他模组；抽中后是**一整行**，玩家卖任意一种刷怪蛋都按这一行结算）

加一个单件奖励：

```json
"pool": [
  "minecraft:nether_star",
  "minecraft:dragon_egg"
],
"basePrices": {
  "minecraft:nether_star": 133,
  "minecraft:dragon_egg": 200
}
```

`basePrices` 里没写的池子条目会用兜底价 100。

**限制某个池子条目一天最多出几件**：

```json
"poolMaxPicks": {
  "#emerald_economy:acquire/heads": 1
}
```

默认就是 1。调大会让同一类一天出现多件（例如把头颅调成 2，就可能一期出现 2 个头颅）。

**查看今天抽到了什么**：`/ee friday`。
**想快速测试**：临时把配置 GUI 里的「疯狂星期五开放间隔」改成 1，
或把游戏时间推到逢 5 的日子。

### 4. 进阶：自己做一个物品标签（datapack）

如果你想让「一整类模组物品」只占收购机的一行，可以做一个标签。

1. 在存档的 `datapacks/` 下新建一个文件夹，例如 `my_tags/`；
2. 在 `my_tags/` 里建 `pack.mcmeta`：

```json
{
  "pack": {
    "pack_format": 48,
    "description": "My custom item tags"
  }
}
```

3. 建文件 `my_tags/data/mymod/tags/item/my_crops.json`：

```json
{
  "values": [
    "farmersdelight:tomato",
    "farmersdelight:cabbage",
    "farmersdelight:onion"
  ]
}
```

4. 在 `acquire.json` 里写：

```json
{
  "tag": "mymod:my_crops",
  "price": 2,
  "name": "模组蔬菜（任意）"
}
```

5. 执行 `/reload`（重新加载数据包），再执行 `/ee reload`。

标签的命名空间（示例里的 `mymod`）可以自己起，但必须是小写字母 / 数字 / 下划线，
并且和文件夹路径一致。不会做数据包的话，直接逐个写 `item` 更简单。

### 5. 进阶：TOML 里的列表型参数

这些参数在配置 GUI 里也能看到，但都是**长列表字符串**，在 GUI 里改很痛苦，
直接编辑 TOML 更现实。文件位置：

- 单人游戏：`saves/<世界名>/serverconfig/emerald_economy-server.toml`
- 专用服务器：`config/` 目录下的 `emerald_economy-server.toml`

常用格式：

```toml
# 各基金基础价：代码=价格
fundBasePrices = ["EMR_MIN=100", "EMR_AGR=80", "EMR_LIV=90", "EMR_BLD=70", "EMR_HYD=85", "EMR_HUN=95", "EMR_CMP=100"]

# 各基金波动率：代码=小数
fundVolatilities = ["EMR_MIN=0.060", "EMR_AGR=0.045", "EMR_LIV=0.040"]

# 天气修正：天气:基金=增量
weatherModifiers = ["RAIN:EMR_AGR=0.080", "THUNDER:EMR_HYD=0.090"]

# 随机市场事件：范围|增量|语言键
marketEvents = ["EMR_MIN|0.08|news.vein_found", "ALL|-0.06|news.recession"]
```

- 基金代码：`EMR_MIN` 矿业、`EMR_AGR` 农业、`EMR_LIV` 畜牧、`EMR_BLD` 建筑、
  `EMR_HYD` 水电、`EMR_HUN` 狩猎、`EMR_CMP` 综合；
- 天气：`CLEAR` 晴、`RAIN` 雨、`THUNDER` 雷暴；
- 市场事件的范围写 `ALL` 或具体基金代码；语言键用现有的 `news.xxx`；
  想写自己的新闻文本需要资源包（进阶）；
- 改完 TOML 后**重启服务器**最稳（在配置 GUI 里改一般会即时生效）。

### 6. 配置没生效？按这个顺序排查

1. **改的是服务端文件吗？** 联机时只改客户端没用。
2. **执行 `/ee reload` 了吗？** 改 JSON 后必须执行；TOML 需要重启。
3. **JSON 是不是写错了？** 看 `logs/latest.log` 里的 `[内容] 解析`；
   常见错误是少逗号、多逗号、少引号、用了中文引号。
4. **物品 ID 对吗？** 用 `/give` 补全核对；物品 ID 必须小写，并且带命名空间。
5. **服务端装了这个模组吗？** 收购 / 售卖的物品来自服务端注册表；
   服务端没装，物品就不存在。
6. **文件是不是旧版本？** 模组升级后不会自动合并新默认内容；
   先备份，再删掉重新生成，或手动补条目。
7. **标签是不是空的？** 标签不存在或没有任何成员时，这一行会被跳过。
8. **分类 / 子分类 ID 重复了吗？** 自己加的 ID 要唯一；
   不要用 `FRIDAY` / `ENCHANT` 作为收购分类 ID。
9. **界面还是旧的？** 关掉机器界面再重新打开；`/ee reload` 会刷新已打开的界面，
   但重开最稳。

## 游戏内命令（需要 OP）

| 命令 | 作用 |
| --- | --- |
| `/ee balance [玩家]` | 查看账户余额 / 欠款 / 信用额度 |
| `/ee give <玩家> <数量>` / `/ee take <玩家> <数量>` | 直接增减账户余额 |
| `/ee price` | 打印七支基金的价格、基准价、涨跌幅、动量 |
| `/ee tick` | 强制刷新一次基金价格 |
| `/ee settle` | **强制跑一次每日结算**（立刻看到开奖、利息、新闻广播） |
| `/ee supply` | 查看当日各行业供给量与当前天气 |
| `/ee friday` | 查看疯狂星期五状态 |
| `/ee setprice <基金代码> <价格>` | 直接设定某支基金价格 |
| `/ee shop reset` | 重置商店限购次数 |
| `/ee reload` | **重新读取 `shop.json` / `acquire.json`**（改完货架与价格表不用重启） |

## 开发

```bash
./gradlew build                    # 编译
python tools/gen_resources.py      # 重新生成方块状态 / 模型 / 配方 / 战利品表 / 配方解锁进度 / 收购标签
python tools/gen_bbmodel.py        # 用同一份几何生成 Blockbench 工程（素材/blockbench/*.bbmodel）
python tools/gen_economy_json.py   # 重新生成内容配置的默认模板（shop.json / acquire.json）
python tools/gen_readme_tables.py zh   # 生成本 README「默认数值与价格总表」那一节的表格（en 生成英文版）
python tools/check_lang.py         # 校验中英翻译键是否齐全（含配置界面）
python tools/setup-dev-server.py   # 一键摆好 run/（超平坦 + 创造 + OP），删过 run/ 之后必须跑一次
java tools/TextureGenerator.java   # 从 素材/logo.png 生成模组图标（抠白底 + 缩放到 256）
```

**机器模型的单一真源**是 `tools/gen_resources.py` 里的 `machine_elements()`；
想用 Blockbench 手工改，就用 `素材/blockbench/*.bbmodel` 打开，改完把几何回填到脚本里。

**价格与数值的单一真源**是 `EEConfig.java`（数值）与 `tools/gen_economy_json.py`（卖什么 / 收什么）；
「默认数值与价格总表」那一节由 `gen_readme_tables.py` 生成，改完默认值重跑脚本、整节替换即可
（脚本用的原版中文名需要 `build/vanilla_lang/zh_cn.json`，脚本头部写了获取命令）。
